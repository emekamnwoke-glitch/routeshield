CH-001 and CH-002 are changes within an open phase, caught by a later sub-phase before baseline. CH-003 changes a plan, not a design. None of them originated in implementation, so none of them satisfies Phase H's exit condition — they show the process working at small scale, not the feedback loop the charter requires.

CH-007 to CH-009 are the first changes to originate in implementation, and so the first run of the [architecture / implementation feedback loop](../methodology/architecture-method.md#6-the-architecture--implementation-feedback-loop). CH-008 also records that the loop was run late: three decisions reached the code before the architecture, which is the shortcut P-11 prohibits. They are recorded, not hidden, and the as-built architecture at [v1.2.0](../../02-stage-two-reference-implementation/solution-design/architecture-v1.2.0.md#7-departures-from-the-stage-one-target) lists every departure from the target with its class and record.
