## What this settles

**The search space is expressed in stops, not roads.** Reroutes are generated by choosing where to leave the pattern and where to rejoin it, then finding a feasible path between the two. Stops lost is a direct property of each candidate instead of something reverse-engineered from a path.

**Hold and terminate are always options.** A reroute is always compared with doing less, so a detour worse than a ten-minute hold says so.

**A stranded passenger outweighs everything else.** Uncovered lost stops weigh far more than covered ones, which weigh more than delay, which weighs far more than vehicle time. The ordering is the decision; the values are demonstration values and labelled as such.

**The optimiser's largest known flaw is displayed.** It treats every stop as equal because stop-criticality data does not exist. Every recommendation says "equity weighting unavailable".

**ML is last and least.** With no history, a model can only learn the synthetic generator's rules. The architecture's real learning mechanisms — the decision record and the governed contingency library — work without ML. Models are suggestions, always reported next to a rule-based baseline.

## The tension recorded

The MVP as scoped leads with routing and delivers nothing to passengers, although Phase A ranked passengers' interests second precisely because nothing else carries them, and the opportunity analysis ranks stop-level notices ahead of ranked options. The MVP is kept for this project — routing is the least certain part and worth de-risking early — but the recommendation for a real operator is to reverse the order.
